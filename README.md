# Merces
Merces is the primary app I've created as a playground for various Apple frameworks.

Usage Examples:
* Autolayout (view rotates, supports split screen and split view on iPad)
* Localization files for English, Spanish, Chinese
* 3D Touch shortcut support via app icon
* "Today widget" possesses the calculator functionality
* NSUserDefaults for saving chosen tax rate, custom venue percentages
* CocoaPods integration for use of Chameleon framework
